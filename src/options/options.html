1.5 过滤类别

        

          关掉某一类 = 该类别**不隐藏、不动作**（宁可漏杀不可误杀）。类别由模型判定，
          本地预筛只负责决定「值不值得花一次调用」。
        

        

          
          
          
          
          
          
        

      


      

        
1.6 α / β 语义信息（折叠重复 · 标记特殊）

        

          β（重复 / 类似 / 语义相同的信息）：同一批推文里说法几乎一样的，
          折叠成只显示一次，其余收进「重复」里 —— 只是折叠展示，
          不隐藏、不动作。

          α（特殊信息）：与评论区多数观点明显不同的推文，
          只标记、不隐藏，照样正常显示，只是加一个「和主流不一样」的提示。
        

        

          两者都不影响隐藏与账号动作：隐藏 / 静音 / 拉黑仍然只由「过滤类别」与
          「置信度闸门」加下面的动作开关决定；α / β 只是在已放行的推文上多做一层整理与提示。
          关掉总开关就等于回到纯类别过滤。
        

        

          
          
          
          
          
          
          
          
          
          
          
          
          
        

        

          语义预算超限时只是「跳过整理」（不折叠、也不标记），不影响类别判定、
          隐藏与账号动作。
        

      


      

        
2. 置信度闸门

        

          账号动作需要同时满足四条：类别本身允许动账号（色情/诈骗/广告导流）、
          类别置信度达标、危害程度达标、以及
          至少一条硬度证据（色情概率 / 欺骗概率 / 强引流）。
          其余情况最多隐藏成「待确认」。双确认是给商业推广留的补充路径：
          色情与站外引流两条独立判定同时过关、且类别置信度极高时也允许进入动作档。
        

        

          
          
          
          
          
          
          
          
          
          
          
          
          
        

      


      

        
2.5 预检（模型先行，召回的关键）

        

          关键词表只是「廉价的怀疑」，不是召回上限：垃圾信息会不断换写法
          （`比我好看的没我骚🔧👏`、emoji 拆字 `处🐕男`、把引流写进显示名），
          词表里没有的写法模型根本看不到。打开预检后，没被词表命中的推文也会被问一句廉价单问
          （「这是不是垃圾/诈骗诱饵/低质填充」），命中才升级为完整五问。
        

        

          命中线 0.65（只隐藏待确认）、升级线 0.75（再问完整四问，可能进入静音/拉黑档）。
          代价：普通推文也会各花一次单问（约为四问的 1/4 成本）。用下面的采样率和预算控制总量，
          不想花这笔钱就把开关关掉，回到「只有候选才调用」的 0 成本模式。
        

        

          
          
          
          
          
          
        

      


      

        
2.8 文案农场（重复刷屏）

        

          真站形态：回复区里 4 个随机账号在同一分钟刷同一句
          应该没人比我玩的开了吧🤣💖我福不黑不信你看。
          单看任意一条连模型都只能说「不确定」（实测诱饵概率 0.54），但「同一段无实质内容的话被
          N 个不同账号短时间内复制」本身就是农场证据。
        

        

          命中后：同文案的推文**全部隐藏**（包括比它更早出现、当时被判放行的那两条），
          归一到「只留中文/字母数字」，所以换 emoji、换标点、改大小写都躲不掉；
          短于 10 个有效字符的内容不参与（避免「哈哈」这类大众短语误伤）。
          是否顺带静音账号由上面的「连隐藏档也静音」开关决定 —— 农场本身不会自动拉黑。
        

        

          
          
          
          
          
        

      


      

        
3. 命中后的动作

        

          账号级动作不可逆：演练模式下只记录「本应静音/拉黑谁」而不点击，请在
          审计日志 里核对几天后再关闭演练。

5. 图片与可选视觉模型

        

          Jev 只能读文本，所以图片默认走本地像素启发式（不出网、只看缩略图），
          只作为佐证信号，永不会单独触发拉黑。若需要更准的图片判定，可另配一个支持
          image_url 的 OpenAI 兼容视觉端点（图片 URL 会发送给该服务）。
