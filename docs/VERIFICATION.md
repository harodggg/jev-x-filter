## 1. 静态自检（`tools/check-sources.js`）

不需要浏览器，检查的是「打包事故」类问题：

- `manifest.json` 合法、MV3、引用到的每个文件都存在
- Service Worker 声明 `type: module`
- 权限最小化：只允许 `storage` / `alarms`；host 权限只允许 x.com/twitter.com、twimg CDN、四个已配置的 Jev 网关
- 内容脚本只注入 x.com/twitter.com（**没有** `<all_urls>`）
- 没有 `web_accessible_resources`
- 打包代码里没有 `eval` / `new Function` / 远程 import / 远程脚本引用
- HTML 没有外链脚本，本地引用齐全
- **内容脚本确实是传统脚本**（出现 `import/export` 就报错，否则页面上会直接语法错误）
- 所有 JS 通过 `node --check`（33 个文件）

陷阱（回应用户真站反馈累积出来的）：
1. 菜单里混入 `Unmute`/`Unblock` 反义项（静音项在多数构建里**没有 testid**，只能按文案匹配）；
2. 页面里预先存在一个文案为 `Block` 的 `confirmationSheetConfirm`（X 会复用这个 testid 到别的弹窗）；
3. **DOM 里预先挂着一个关闭状态的残留 `Dropdown`**（`data-stale`，`display:none`），
   里面的静音项写着**别的账号** —— 取「文档里第一个 Dropdown」就会静音错人；
4. 菜单浮层**依赖触发按钮的 rect**：夹具照抄真站行为 —— `⋯` 按钮没有盒子就拒开菜单，
   这正是真站 `自动动作失败：menu_item_not_found:mute` 的根因（隐藏后 `⋯` 的 rect 是 0×0）；
5. 菜单项**异步渲染**（点击后 ~450ms 才出现），且静音项文案随语言变化
   （西语 `Silenciar` + 反义 `Dejar de silenciar`；另一条只有 `data-testid="mute"`、文案不可匹配）；
6. 一条推文的菜单里**确实没有**静音项 —— 实现必须失败并留下「菜单里有什么」的诊断，绝不猜点。

54 项断言分七组：

1. **场景 A（演练）**：三条被隐藏、三条保持可见、判定条写清概率与原因、没有点任何菜单
2. **Jev 协议**：≥4 次调用、路径 `/v1/systemone`、`Authorization: Bearer e2e-key`、
   `Content-Type`/`Accept`、UA 由浏览器接管（平台限制）、`model` 来自设置、body 含 `state` + 四个类型化问题、
   普通推文没有触发调用
3. **SW 侧**：找到 Service Worker 目标、`mediaAnalyzed ≥ 2`（OffscreenCanvas 真的跑通）、
   block 档 ≥ 2、无调用失败/答案残缺、审计里记录了「演练模式下本应执行」且原因 `dry_run`
4. **审计 webhook**：收到 `decision` / `hidden` 事件，带 source 与 version；页面无脚本异常
5. **场景 B（武装静音 + 只分析视口）**：IntersectionObserver 路径生效、静音点中 `spammer1` 与 `escort4`、
   不点拉黑、不点反义项、弱信号推文不被静音、**动作数恰好 2（幂等）**、审计记录真实执行
6. **场景 C（武装拉黑）**：点的是拉黑不是静音、点中新出现的确认按钮、不点反义项、
   **不点页面里预先存在的同名确认框**、动作不重复、隐藏结果与场景 A 一致
7. **场景 D（武装 + 隐藏档也静音）**：农场账号被静音；`review` 档（纯图/无关键词诱饵）仍然不动作；
   隐藏档静音不会升级为拉黑；页面无脚本异常
8. **场景 E（α / β 语义层）**：α 命中的回复带 `α` 徽标且**仍完整可见**；线程内语义相同的回复被 β 折叠
   （代表条不折叠）；SW 统计里 `calls / candidateSets / alphaHits / betaFolds ≥ 1`（**在刚跑完场景 E 时读**，
   因为设置页那次读取可能跨过 Service Worker 重启、内存计数归零）
9. **场景 F（菜单自动化鲁棒性，真站 `menu_item_not_found:mute` 的回归）**：
   ① 每次点 `⋯` 时触发按钮的 rect 都 > 0（`window.__menuCalls`，证明「隐藏后临时恢复可渲染」生效）；
   ② 西语菜单项（含反义项）点的是静音；③ 只有 `data-testid="mute"`、文案不可匹配的项也能命中；
   ④ 没有点到反义项；⑤ **没有点到残留菜单里的假条目**（`Mute @stale_ghost`）；
   ⑥ 菜单里没有静音项时绝不猜点（关注/不感兴趣/拉黑都不点）；
   ⑦ 失败提示是人话且给出「重试」指引，`title` 里带上菜单项清单；
   ⑧ `summary().actionErrors` 里能查到 `menu_item_not_found:mute` 与其诊断
10. **场景 G（X 自己的「可能的垃圾信息」分区 + 8 字同句农场）**：
   ① 分区**外面**的 3 字推文仍然保持可见（本地过短跳过，不被顺手隐藏）；
   ② 分区**里面**的 3 字推文被隐藏成 `review`，原因是 `x_spam_section`（判定条上写明「X 自己把这批内容标为…」）；
   ③ 两条同句（只差 emoji、归一化后 8 个字符）被隐藏且命中 `farm_repeat`（阈值 10 时这对整条不参与判定）；
   ④ 结构信号与隐藏档都不产生账号动作；⑤ SW 统计 `farmHits ≥ 1`、审计里能看到 `x_spam_section`。
11. **场景 H（情绪言论：折叠 / 隐藏 + 类别标记）**：
   fold 模式下① 愤怒同类里第一条是代表条（挂「情绪 · 愤怒」徽标、不折叠）、② 第二条折叠且条文写明「情绪 · 愤怒」、
   ③ 喜悦同类折叠带「情绪 · 喜悦」标签、④ 支持/反对这类单条也各自挂徽标、
   ⑤ 讲理由的回复（「我不同意，因为…」）绝不折叠也不标情绪、⑥ 不产生账号动作；
   hide 模式下⑦ 代表条也折叠（一条都不显示）、⑧ 支持/反对单条同样折叠、⑨ 条文写明「已隐藏」、⑩ 论点仍然不折叠。
   （情绪层是**纯本地**的，live-check 不覆盖它：覆盖来自 `tests/lowSignal.test.js` 8 组 + `tests/pipeline.test.js` 3 组 + 本场景 13 项断言。）
12. **场景 I（时间线情绪言论，feed 范围）**：时间线夹具里 6 条情绪短句（`交朋友`/`美女啊`/`👍好`/`我也想去`/`Gm`/`太美了`）
   全部折叠且条文写明类别（社交/赞美/支持/期待/问候/赞美）并带原文预览；
   讲理由的回复与普通内容保持可见；不产生账号动作。
13. **扩展页面**：设置页 81 字段 / 5 预设渲染完整、α/β 语义节 12 个字段、保存阈值后 SW 回读一致、
   显示「模型就绪 · custom · jev-test」、「测试连接」拿到类型化答案、弹窗 8 格统计与模型状态、
   弹窗 β 开关能真实翻转设置、黑名单自动记账 + 导入 2 条 + 导出包含全部账号、
   三个页面均无脚本异常

## 4. 本轮验证抓到的真实问题

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 「测试连接」报 `import() is disallowed on ServiceWorkerGlobalScope` | MV3 SW 禁止动态 `import()` | `JEVX_TEST_CONNECTION` 里那句 `await import('./classifier.js')` 改为顶层静态 import |
| 动作日志里 `spammer1` 被静音两次 | 注入的判定条改变了 `article.textContent` → 内容签名变化 → 被误判为「节点复用」→ 重新判定并再次动作 | 签名只取作者/文案节点；账号动作按 `handle:kind` 幂等 |
| 演练模式占用了每日动作预算 | 计数放在 `kind !== 'none'` | 改为只有 `execute === true` 才扣额度 |
| 端到端收尾 `ENOTEMPTY` 删不掉 Chrome profile | 未等 Chrome 退出就删目录 | 等 `exit` 事件 + `rmSync` 重试 |
| 断言 `User-Agent: jev-systemone/...` 失败 | 浏览器把 `User-Agent` 当受限请求头，忽略脚本设置 | 文档标注为平台限制，端到端改为显式断言「UA 由浏览器接管」 |
| 商业色情推广（OnlyFans 促销）真实概率 0.85/0.86，单条阈值 0.9 → 只隐藏不静音 | 真实模型验证 | 新增「双确认」路径：两个独立 Noul ≥0.80 + 类别置信度 ≥0.95 才升级为 block |
| 纯图片黄推（文案「看」+ 色情图）真实文本概率仅 0.21 → 整条被放行 | 真实模型验证（Jev 看不了图） | 「只发图/纯链接形态 + 图片极可能裸露」→ 隐藏成待确认，仍不动账号 |
| 「极可能裸露」阈值 0.62 会把泳装照（实测肤色 0.62）判成裸露 | 真实模型验证 | 默认提到 0.70；泳装样本回落到「可疑」，需本地文案信号配合才会隐藏 |
| **文案农场刷屏**：4 个账号同分钟刷同一句，单条诱饵概率只有 0.47–0.54 → 整批漏过 | 用户截图反馈 | 新增 `src/sw/farm.js`：同文案 ≥3 个不同账号（30 分钟窗口，归一化吃掉 emoji/标点）→ `hide`；内容脚本按归一化键追溯隐藏更早的条目；配套「连隐藏档也静音」开关 |
| **缓存指纹不全**：切换「自动静音」后已缓存推文仍按旧配置动作 | 端到端场景 D 失败 | 指纹补上 `action`/`triage`/`farm`/`media`/`budget`；新增单测「改动作配置必须缓存未命中」 |
| 端到端测试自身的竞态：写完配置只 `sleep 600ms`，场景 D 拿到场景 C 的配置 | 同一轮失败 | `configure()` 改为轮询 Service Worker 真实状态直至生效 |
| **v0.2 的「强类别」假设不通用**：闸门只认色情类别，无法表达「诈骗可动账号、标题党不可动」 | v0.3 类别化重构 | 类别事实表 `categories.js` 单点定义 `accountEligible`/`hideable`/分组开关；闸门与 UI/统计/审计全部读它 |
| 关掉「色情」类别后，兜底路径（成人概率 ≥0.5、肤色、视觉模型、显示名引流）仍在隐藏 | 单测暴露 | 所有隐藏路径都加类别开关约束，并逐条加断言 |
| **emoji 拆字规避**：显示名写「处男免费」、正文写「处🐕男」，预筛 score=0（「处男」在原文里不存在） | 用户截图（第 4 轮样本） | 新增 `stripSymbols()`：规则同时对原文与「去 emoji/符号/空白后的密集文本」匹配；`处🐕男 → 处男` |
| 同一句黑话同时出现在显示名与正文里，却只算一分（弱特征对拼接后的整串只匹配一次） | 同上 | 弱特征改为**按显示名 / 正文分开计分**（两处命中 = 2 分 = 候选） |

## 6. 没被自动化覆盖的部分（诚实清单）

- **关键词型绕过**：真站样本说明黄推会持续换写法（`约p`、`约🅿️`、拼音、emoji 夹字、把引流写进显示名/卡片）。
  预筛是白盒正则，能快速补；但**不要指望它穷举**，它是「决定是否问模型的廉价筛子」，
  真正的判定在模型那一层（所以显示名等新载体一定要进 state）。
- **真实 x.com 页面**：夹具页面复刻了推文结构、菜单与确认框，但真实站点的类名、虚拟列表行为、
  多语言文案都会漂移。上线前请先用演练模式在你自己的时间线上跑几天。
- **真实 Jev 网关**：主验证走 mock 网关；真实网关由 `tools/live-check.js` 覆盖（见 §5，含延迟与 token），
  设置页的「测试连接」也可随时验证你的 Key/额度。`state` 上限（约 32k token）本扩展按 4000 字符截断。
  不同网关/模型的**校准差异**仍可能有：换 Key 或换模型后建议重跑一次 `live-check`。
- **视觉模型适配器**：只做了注入式单测（请求体、回答校验、错误路径），没有对真实多模态端点做过调用。
- **拉黑确认框的中文文案**：`confirmationSheetConfirm` 是结构判定 + 文案校验，中文文案未在源码中确认，
  因此实现以结构为主、文案为辅。
- **风控行为**：无法在测试中验证 X 对自动化的容忍度；默认限速与演练模式是工程上的保守选择。
